## Susunan pengumpulan

Setiap folder modul memiliki folder `Project/` untuk kode sumber. Apabila satu modul berisi beberapa percobaan, simpan masing-masing project dalam subfolder terpisah. Laporan PDF dapat diletakkan di folder modul yang bersangkutan.

Contoh: `Modul 05/Project/demo_card/pubspec.yaml` dan `Modul 05/Project/music_card/pubspec.yaml`.

## Menjalankan project

Buka terminal pada folder project yang berisi `pubspec.yaml`, kemudian jalankan:

```bash
flutter pub get
flutter run
```

Gunakan Flutter SDK dan Dart yang sesuai dengan batas versi dalam `pubspec.yaml` masing-masing project.

## Menambahkan hasil praktikum

1. Salin project ke folder modul yang sesuai, dengan tetap menyertakan `lib/`, `pubspec.yaml`, aset, dan folder platform.
2. Jangan menyalin folder `.git` dari project lain ke repository ini.
3. Tambahkan laporan jika tersedia dan perbarui status pada tabel di atas.
4. Dari folder utama repository, jalankan:

```bash
git status
git add .
git commit -m "Tambah hasil praktikum"
git push origin main
```

Folder build dan cache diabaikan melalui `.gitignore`.
